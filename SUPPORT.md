# Support

Use GitHub Discussions for setup questions and GitHub Issues for reproducible
bugs or feature requests. Include OpenClaw, Node.js, VS Code, Quota Pilot, and
operating-system versions plus the smallest safe reproduction.

Do not publish credentials, configuration files, databases, session files,
account IDs, tokens, private email addresses, or raw diagnostic bundles.
Security vulnerabilities belong in a private security advisory as described
in [SECURITY.md](SECURITY.md).
